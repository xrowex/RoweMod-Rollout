# Contributing to RoweMod × Rollout

- Keep **Track A** examples as JSON-only tints/rows. Do not check in extracted game meshes or `dumps/`.
- New items go under `items/<slot>/` with a `row` ending in `-mod`.
- Track B meshes stay on `main-rig`. Cook paths must stay under `/Game/MainFolder/...`. Never pack `main-rig` or `MI-Upper`.
- Preview icons for mods can use a cyan frame (`art/make_mod_previews.py`) so they read as custom in the catalog.
